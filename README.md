### What I'm building

**[ORANO — Orano AI](https://oranoai.com/)** · iOS + Android

> Stop scrolling. Start doing.

You save Reels, YouTube videos, articles, and PDFs — then never act on them. ORANO turns each save into a structured project: a summary, key takeaways, an ordered action plan or learning roadmap. Your saved library becomes personal memory that your own AI agent (ChatGPT, Claude, Cursor, Ollama) can read through a personal, read-only MCP server.

### The loop I keep coming back to

**capture → understand → plan → execute → remember → hand off to your agent.**

Most tools stop at capture. The useful part starts after.
